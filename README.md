# Одномерный фотонный кристалл

Расчёт спектров **отражения** и **пропускания** одномерного фотонного кристалла
(брэгговской стопки) методом характеристических матриц. Две программы с
графическим интерфейсом позволяют менять параметры структуры и сразу видеть,
как меняется спектр.

| | |
|---|---|
| `reflection.py` | Спектр отражения `R(λ)` стопки `(HL)^N` или `(LH)^N` — как формируется запрещённая зона |
| `transmission.py` | Спектр пропускания `T(λ)` структуры с дефектом `(HL)^N D (LH)^N` — дефектная мода внутри зоны |
| `optical_core.py` | Расчётное ядро: матрицы слоёв, сборка структур, коэффициенты `R` и `T` |
| `Graphiks/` | Графики, полученные в этих программах |

## Запуск

```bash
pip install -r requirements.txt

python reflection.py      # окно со спектром отражения
python transmission.py    # окно со спектром пропускания
```

Нужен Python 3.10+ (используется синтаксис `float | int` в аннотациях) и
установленный `tkinter` — в Windows и macOS он идёт вместе с Python, в Linux
ставится отдельно: `sudo apt install python3-tk`.

## Физическая модель

Свет падает **нормально** на стопку плоскопараллельных слоёв. Каждому слою
отвечает характеристическая матрица

```
        ⎡   cos δ      (i/n)·sin δ ⎤                 2π·n·h
M(n,h) = ⎢                          ⎥,        δ = ──────────
        ⎣ i·n·sin δ      cos δ      ⎦                  λ
```

где `n` — показатель преломления слоя, `h` — его геометрическая толщина,
`δ` — набег фазы. Матрица всей структуры есть произведение матриц слоёв в
порядке их прохождения:

```
M = M₁ · M₂ · … · M_k = ⎡ a  b ⎤
                        ⎣ c  d ⎦
```

Через элементы полной матрицы и показатели преломления входной (`n_in`) и
выходной (`n_out`) сред выражаются амплитудные коэффициенты:

```
r = (n_in·a + n_in·n_out·b − c − n_out·d) / D
t = 2·n_in / D,        D = n_in·a + n_in·n_out·b + c + n_out·d
```

и энергетические коэффициенты

```
R = |r|²,        T = (n_out/n_in)·|t|²
```

Для прозрачной (непоглощающей) структуры выполняется `R + T = 1` — это
служит основным контролем правильности расчёта.

### Единицы

Все длины заданы в долях расчётной длины волны `λ₀` (в коде `LAMBDA_0 = 1`).
Толщина `h_H = 0.125` означает `h_H = 0.125·λ₀`; ось абсцисс на графиках —
безразмерная величина `λ/λ₀`.

Ключевая характеристика слоя — **оптическая толщина** `n·h/λ₀`:

* `n·h/λ₀ = 1/4` — четвертьволновой слой; из таких слоёв строится зеркало с
  максимальным отражением на `λ₀`;
* `n·h/λ₀ = 1/2` — полуволновой слой; на `λ₀` он «невидим» (не отражает), а в
  роли дефекта открывает узкий пик пропускания.

Обе программы показывают текущее значение `n·h/λ₀` под полями ввода и
подписывают, когда слой оказывается четверть- или полуволновым.

### Что моделируется, а что нет

Модель намеренно упрощена до учебной задачи:

* **есть:** произвольное число слоёв, произвольные `n` и `h`, дефектный слой,
  сравнение структур с разным числом периодов;
* **нет:** наклонного падения (только нормальное), поляризации, дисперсии
  `n(λ)`, поглощения (`n` вещественный), подложки — среды слева и справа
  считаются воздухом (`N_IN = N_OUT = 1`).

## Интерфейс

Общее для обеих программ:

* **Поля ввода** принимают числа в виде `0.125`, `0,125` или дроби `1/8` —
  последнее удобно для записи `λ₀/8`.
* **«Построить график»** — пересчёт и перерисовка; **«Сбросить параметры»** —
  возврат к значениям по умолчанию.
* **«Сохранить график»** — экспорт в PNG/PDF/SVG с разрешением 300 dpi.
* Неверный ввод не роняет программу: выводится окно с описанием ошибки и
  названием поля, в котором она допущена.

### `reflection.py`

Поле «Число периодов N» принимает **список** значений через запятую
(например, `2, 4, 8`) — на одном графике строится несколько кривых, что и
показывает, как с ростом `N` растёт отражение и формируется плоская вершина
запрещённой зоны. Переключатель выбирает, с какого слоя начинается период:
`(HL)^N` или `(LH)^N`.

### `transmission.py`

Задаются параметры зеркал (`n_H, h_H, n_L, h_L`), дефекта (`n_D, h_D`) и число
периодов `N` **с каждой стороны** от дефекта. Флажок «Показывать обычную стопку
без дефекта» добавляет на график кривую `(HL)^{2N}` — для сравнения видно, что
дефект открывает узкий пик пропускания ровно там, где сплошная стопка не
пропускает ничего.

## Проверка расчёта

Правильность ядра подтверждается совпадением с известными аналитическими
результатами:

* `R + T = 1` (с точностью до ошибок округления) для любых непоглощающих
  структур — закон сохранения энергии;
* полуволновой слой не отражает: `R = 0`;
* для одиночной четвертьволновой плёнки в воздухе
  `R = ((1 − n²)/(1 + n²))²`;
* для зеркала `(HL)^N` на `λ₀` расчёт совпадает с формулой эффективного
  адмиттанса `Y = (n_H/n_L)^{2N}`, `R = ((1 − Y)/(1 + Y))²`;
* `det M = 1` для матрицы слоя и для матрицы всей структуры
  (унимодулярность характеристических матриц).
