Краткий комментарий к Python-кодам

Файлы независимые: каждый .py можно запускать отдельно командой:
python имя_файла.py

Для работы нужны:
numpy
matplotlib

Что строят файлы:

1. optical_core.py
Общее расчётное ядро.
В нём находятся матрица слоя, матрица всей стопки,
коэффициенты отражения/пропускания и функции построения структур:
(HL)^N, (LH)^N и (HL)^N D (LH)^N.

2. reflection.py
Файл с простым оконным интерфейсом для отражения.
В интерфейсе можно задать физические толщины пластинок H и L,
показатели преломления nH и nL, первый слой периода, список N,
диапазон длин волн и количество точек.
Оптические толщины n*h/lambda0 показываются автоматически.
График строится в окне и автоматически не сохраняется.

3. transmission.py
Файл с простым оконным интерфейсом для пропускания с дефектной пластинкой.
В интерфейсе можно задать физические толщины H, L и D в долях lambda0,
показатели преломления nH, nL и nD, число периодов N,
диапазон длин волн и количество точек.
Оптические толщины n*h/lambda0 показываются автоматически.
По умолчанию H и L четвертьволновые, а D полуволновой.
На графике строятся две кривые: без дефекта и с одной дефектной пластинкой.
График строится в окне и автоматически не сохраняется.

Физическая модель:
используется матричный метод тонких диэлектрических слоёв при нормальном падении.

Матрица одного слоя:
M_j =
[[cos(delta_j), i sin(delta_j)/n_j],
 [i n_j sin(delta_j), cos(delta_j)]]

delta_j = 2*pi*n_j*h_j/lambda.

Коэффициенты отражения и пропускания находятся из полной матрицы всей стопки.
